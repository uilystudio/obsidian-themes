## Features

- Six coordinated variants: five dark themes and one light theme.
- Native VS Code colors for the editor, sidebar, tabs, terminal and other workbench elements.
- TextMate and semantic-token syntax highlighting with subtle, readable contrast.
- No custom CSS, no runtime code, and no changes to your editor settings.

## Language coloring

Obsidian Themes includes additional coloring rules for **JavaScript, TypeScript, JSX/TSX, HTML, CSS, SCSS, Python, Rust, Go, Java, C/C++, C#, Kotlin, PHP, Ruby, Swift, Dart, Lua/Luau (Roblox), SQL, GraphQL, JSON, YAML, TOML, Bash, PowerShell, Markdown** and more.

The exact result depends on the TextMate grammar and semantic tokens available for the language. Some languages require a separate language-support extension; Obsidian Themes itself only changes colors.

## Getting started

1. Install **Obsidian Themes** from Visual Studio Code Marketplace, or install a local `.vsix` using **Extensions → … → Install from VSIX...**.
2. Press `Ctrl+K`, then `Ctrl+T` to open the theme selector.
3. Select your preferred Obsidian theme.
