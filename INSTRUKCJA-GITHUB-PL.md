# Publikowanie Obsidian Themes 2.0.3 na GitHubie

1. Otwórz https://github.com/uilystudio/obsidian-themes
2. Przejdź do Code → Add file → Upload files (lub Quick setup → uploading an existing file).
3. Rozpakuj Obsidian-Themes-2.0.3-GitHub-READY.zip. Prześlij zawartość katalogu, nie katalog nadrzędny.
4. Zatwierdź commit np. `docs: update theme gallery screenshots`.
5. Sprawdź obrazy w README: wszystkie sześć musi być widocznych.

UWAGA: README korzysta z obrazów pod publicznymi adresami raw.githubusercontent.com na gałęzi main. Będą dostępne dopiero po dodaniu plików.

Nowa wersja w package.json: 2.0.3 (aby Marketplace mógł przyjąć aktualizację). Zmianie uległa tylko dokumentacja i grafiki, nie pliki motywów.
